# 一间好自习：工作台零基础使用说明

全部样例均为模拟场景，不代表实测、真实部署或用户试验。支持矩形房间、一个门、最多3件固定家具、1—12个桌椅工作位及0°/90°两个朝向。尺寸统一为米；通行宽度是计算参数，不构成消防认证。

## 打开与服务恢复

双击项目根目录的 `一键打开工作台.cmd`。脚本检查并复用本机 Node、AGH 4177 和本项目4319服务，缺失时才启动指定服务。等待检查完成后会打开 <http://127.0.0.1:4319/>。也可在服务已在线时直接打开此地址。不要双击 `workbench.html`，file:// 页面不能提交本地任务。

完整网页说明在 <http://127.0.0.1:4319/guide.html>。若服务尚未加载新说明路由，请由服务托管者重新加载本项目 API；不要结束无关进程。

启动失败先看中文提示及 `logs/workbench-launch.log`、`logs/workbench-product.err.log`、`logs/workbench-agh.err.log`。端口被其他应用占用时脚本会停止，不杀进程或抢占端口。AGH需已配置 gpt-6-astra，经 ToTokens `https://totokens.cc/v1` 的 Responses 接口；密钥仅由 AGH 保管，不填入页面或项目文件。代理只在启动进程环境设置，不改变系统设置。

## 熟悉草稿与历史回放

1. 点击“载入6座例子”载入模拟草稿，不调用模型。可先保留原参数熟悉界面。
2. 点击“查看已验证6座示例”通过 GET 读取已有 normal 成功任务 `c13f1131a17f4160be0654a4d08ee475` 的真实输入、验收与资产。它是历史回放，本次未调用模型；不要将历史事件时间和用量称为本次执行。
3. 首次打开不会自动恢复旧任务。需要时点击“恢复上次任务”；运行时输入和载入按钮锁定。

## 填房间、门和家具

房间宽度沿X、深度沿Z，原点为西南角 `(0,0)`；画布南墙在上、北墙在下。南/北墙门偏移从西端沿X量，东/西墙从南端沿Z量。门起点偏移不可留空且须非负，门宽加偏移不得超过墙长。

点击“添加家具”，在表格中填写名称、中心X/Z、宽/深/高；所有尺寸为米。家具须完整处于房间内，最多3件。空字段不会按零处理。删除只移除所选家具。高级 JSON 与表格同步；语法错误不会清空已有表格，修正后可重试。例如：

```json
[{"id":"柜子","x":5.55,"z":4.55,"width":0.5,"depth":0.5,"height":1.8}]
```

网格最小0.02米；资源上限为 `(ceil(宽/网格)+1)*(ceil(深/网格)+1) <= 250000`。自然语言需求会进入真实 AGH 任务；窗户/采光暂未纳入约束，不会被当作已支持。

## 新建真实任务与结果

确认输入后点击“通过 AGH 生成”一次。页面会先校验输入，再建立真实产品 AGH 任务。模型为 gpt-6-astra，渠道 ToTokens，接口 Responses；布局计算、固定行列基线比较、独立验收和资产检查通过明确代码工具执行。模型实际底层提供方及快照版本如未独立核实，应按任务记录如实说明。

观察默认可见的实际执行链、任务ID和业务/AGH状态；高级区保留原始状态与用量。任务结束不自动等于验收通过。搜索与独立验收分离；需完成导出后最终复核。预算内未找到不代表全局无解或已证明最优。

通过且存在本任务GLB后，点击“3D 旋转”，在查看器拖动旋转、滚轮缩放，可切换墙体和编号。下载 `scene.glb`（标准3D资产）、`editable.json`（可编辑输入与布局）、`plan.svg`、`verify.json` 和真实事件链。修改输入会清除旧任务绑定、3D入口和下载；原始任务目录仍保留，不会改写历史结果。

## 故障注入与失败恢复

默认使用 normal 模式。高级“测试故障注入与修复”用于验证越界反馈及按原约束纠错，必须明确标为测试。载入示例会关闭该模式并恢复示例朝向。

门/家具/JSON校验错误：按中文提示修正后再提交。轮询连接失败：确认服务恢复，按界面提示恢复同一任务，保留原失败状态与日志。账号、额度或不支持模型错误：先处理配置，不连续重试。不要将部分步骤完成写成整件作品成功。

## 3—5分钟实际录制流程

1. 0:00—0:25 展示作品名、模拟场景声明及HTTP入口。
2. 0:25—0:55 载入6座草稿，说明尚未执行。
3. 0:55—1:20 回放历史成功案例，明确只读、本次未调用模型。
4. 1:20—1:55 演示米制房间、门偏移、家具中心坐标和增删，再载入样例。
5. 1:55—3:00 提交一次新的normal真实任务，拍到任务ID、实际工具链和状态。
6. 3:00—3:40 查看独立验收、基线比较及导出复核；若失败或超时据实说明。
7. 3:40—4:30 展示本任务真实GLB旋转/缩放与下载可编辑资产。

异常演示可选：打开高级测试故障注入，明确标记“测试”，展示 check-draft 失败反馈→按原约束修复→独立验收。实际耗时取决于网络与执行情况，不承诺一分钟完成。以实际录制为准；运行超时可另做真实后续片段并注明时间变化，不用历史回放冒充本次任务，不制造假进度或成功画面。
