## 模型、工具与限制

产品实际记录的模型为 `gpt-6-astra`，接入 ToTokens `https://totokens.cc/v1` Responses；真实调用、用量、任务/会话 ID 与 Native `shell` tool/call/result 证据见各 job 文件及脱敏导出。底层提供方独立核验状态为未核实，版本快照未观察，不扩大宣称。布局搜索、固定行列基线、schema、独立几何验收和资产一致性检查由项目内确定性代码工具完成，不冒称由模型直接计算。项目依赖记录含 `three@0.180.0`、`gltf-validator@2.0.0-dev.3.10`；Playwright 为本地 UI 测试工具；AGH SDK 及随附许可证留存于项目 vendor。密钥不写入项目代码。

全部样例均为模拟场景，无真实测量、部署或用户试验。通行宽度是产品约束，不是消防认证。门扇回转采用保守矩形近似，不能等同精确圆弧。有限搜索未找到不代表无解；当前结果不声称全局最优。原始独立完成声明仍待学生本人核对签署。
